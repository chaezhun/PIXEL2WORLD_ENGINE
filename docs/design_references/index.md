# 이벤트 카메라 월드 좌표 매핑 가속기 기술문서

> 2026 전국 대학생 AI반도체 회로설계 경진대회 디지털 부문 · 팀 알이즈웰
> 회전하는 카메라에서 나온 변화 기록을 고정된 좌표에 모으는 디지털 회로

---

## 1. 이 문서에 대하여

카메라를 돌리면 화면 속 물체의 위치도 달라집니다. 이 프로젝트는 **카메라가 돈 만큼 좌표를 되돌려,
가만히 있는 물체의 기록이 같은 메모리 칸에 쌓이게 하는 회로**를 만들었습니다. 입력은 일반 동영상의 사진이
아니라, 어느 픽셀이 밝아지거나 어두워졌는지를 기록한 이벤트 데이터입니다.

이 문서는 이벤트 카메라나 반도체 설계를 처음 접하는 독자를 기준으로 씁니다. 먼저 용어와 작은 예제로
동작을 설명하고, 이어서 실제 정수 연산 · 회로 · 검증 결과를 설명합니다. 회로가 처리할 입력과 소프트웨어가
미리 구할 값을 구분하고, 도구로 확인한 로직 수치와 SRAM에 둔 가정치도 구분합니다.

설계 사양은 이 문서가 정본입니다. 어떤 대안을 비교해서 이 설계를 골랐는지는
[설계 근거](../reports/01_설계_근거.md)에, 실행 당시의 로그와 리포트는 각 근거 묶음에 있습니다.
폐기한 설계가 있는 `trash_bin/`은 현재 설계의 근거로 쓰지 않습니다.

## 3. 읽는 순서

프로젝트가 무엇을 했는지부터 알고 싶으면 **1장 → 6장 → 5장** 순서로 읽으십시오. 입력의 뜻을 이해한 뒤
결과 그림과 성능 표를 볼 수 있습니다. 회로를 구현하거나 수정할 독자는 **2장 → 3장 → 4장**을 이어 읽고,
실제로 실행할 때 7장을 보십시오. 용어가 막히면 8장에서 찾아볼 수 있습니다.

각 장의 앞부분은 쉬운 설명이고, 비트 위치 · 수식 · 포트 표는 구현을 위한 상세 사양입니다.
처음 읽을 때 상세 표를 모두 외울 필요는 없습니다. 장 머리의 이전 · 다음 링크로 순서대로 읽을 수 있습니다.
